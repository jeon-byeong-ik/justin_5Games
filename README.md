# 학습 게임 아케이드 (Learning Arcade)

5명의 영웅과 함께하는 5가지 두뇌 게임 모음 — 수학 · 영어 · 과학.
순수 HTML/CSS/JavaScript로 제작되어 별도 설치 없이 브라우저에서 바로 실행됩니다.

## 게임 목록

| 게임 | 과목 | 내용 |
|------|------|------|
| 🚀 구구단 슈팅 | 수학 | 곱셈·나눗셈·혼합 6단계, 스피드 보너스 |
| 🐉 단어 낙하 | 영어 | 7개 테마 230+단어, 황금 단어 보너스 |
| 💎 도형 방어전 | 수학 | 넓이·둘레·홀짝 등 6가지 규칙, 황금 도형 |
| 🪐 태양계 탐험대 | 과학 | 14개 천체·42퀴즈, 매번 다른 출제 |
| 🌿 먹이사슬 퍼즐 | 과학 | 17개 생태계, 분해자 개념, 드래그/탭 배치 |

## 공통 기능

- 5명의 영웅(CALC-9 · STELLAN · VOXA · GAIA · PRISM) 선택, 각자 고유 능력
- 난이도 단계, 점수·콤보 시스템, 최고기록 저장(localStorage)
- 효과음(Web Audio API) 및 음소거 버튼
- 키보드 + 터치 모두 지원

## 실행 방법

`index.html`을 브라우저에서 열면 허브 화면이 나오고, 거기서 각 게임으로 이동합니다.

## 라이선스

캐릭터·코드 모두 직접 제작한 오리지널 콘텐츠입니다.
